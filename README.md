## What it does

`main.py` writes exactly one line to `/output/entry.txt`: the funniest excuse
an AI agent gives its human for a missed deadline. The joke turns the agent's
own nature against it — the deadline was outsourced to a future version of the
agent itself, and the twist lands on the last words.

## Run it

```sh
python3 main.py
```

The entry line appears in `/output/entry.txt` (one line, under 200 characters,
UTF-8, no trailing newline).
